# 闪屏替换指南

闪屏是**原生覆盖层**，不是 RN 页面，也不走 `src/assets/`。  
JS 只负责在导航就绪后 `SplashScreen.hide()`。

Seed 默认是通用图（「RNOH Seed / React Native」），不含具体项目或单位信息。换品牌图时：三端各自替换资源。没有公共拷贝脚本，文件名不要改。

隐藏时机见：[路由导航流程与逻辑](./路由导航流程与逻辑.md)。

---

## 一句话怎么换

| 平台                       | 替换这个文件                                                | 不要改的名字                 |
| -------------------------- | ----------------------------------------------------------- | ---------------------------- |
| **Android**                | `android/app/src/main/res/drawable/launch_screen.png`       | `launch_screen`              |
| **Harmony 整屏**           | `harmony/entry/src/main/resources/base/media/splashImg.png` | `splashImg`                  |
| **Harmony 系统启动小图标** | `harmony/entry/src/main/resources/base/media/startIcon.png` | `startIcon`                  |
| **iOS**                    | 改 `ios/SAMRApp/LaunchScreen.storyboard`（当前不是 PNG）    | Storyboard 名 `LaunchScreen` |

覆盖后重新编译安装（热更新 / Metro reload 不会更新原生资源）。

---

## 图怎么做

闪屏图是**一张完整竖屏合成图**（插画 + 标题 + 单位名都画进 PNG），不是代码拼的。

建议：

- 竖屏全屏构图，主体偏中下，四周留白，避免刘海 / 底部条裁切关键文字
- 格式：PNG
- 分辨率参考现有图（约竖屏全屏，如 1080×1920 或更高）
- Android / Harmony 各放一份；内容可以相同
- Harmony `startIcon` 是**小方图标**（系统 startWindow），不是整屏闪屏，不要拿全屏海报去替换它

## Android

### 替换

1. 导出 PNG，命名为 `launch_screen.png`
2. 覆盖：

```
android/app/src/main/res/drawable/launch_screen.png
```

3. 重新编译 Android

布局引用（一般不用动）：

```
android/app/src/main/res/layout/launch_screen.xml
```

白底 + `fitCenter` 显示 `@drawable/launch_screen`。

### 显示 / 关闭

- 显示：`MainActivity.onCreate` 里先 `SplashScreen.show(this)`，再 `super.onCreate`
- 关闭：`src/navigation/rootStack.tsx` 的 `NavigationContainer.onReady` → `SplashScreen.hide()`

## HarmonyOS

鸿蒙有两层：

| 层               | 资源                   | 作用                                  |
| ---------------- | ---------------------- | ------------------------------------- |
| 系统 startWindow | `startIcon.png` + 白底 | Ability 起来前系统自动显示            |
| 自定义子窗口     | `splashImg.png`        | RN 加载期间盖住白屏，直到 JS `hide()` |

### 替换整屏闪屏

1. 导出 PNG，命名为 `splashImg.png`
2. 覆盖：

```
harmony/entry/src/main/resources/base/media/splashImg.png
```

3. DevEco 重新编译运行

引用位置（一般不用动）：

- `harmony/entry/src/main/ets/entryability/EntryAbility.ets`  
  `$r('app.media.splashImg')`
- 页面壳：`harmony/entry/src/main/ets/pages/SplashScreenPage.ets`
- 库内部按 `ImageFit.Cover` 铺满

### 替换系统启动小图标（可选）

覆盖：

```
harmony/entry/src/main/resources/base/media/startIcon.png
```

配置在 `harmony/entry/src/main/module.json5`：

- `startWindowIcon`: `$media:startIcon`
- `startWindowBackground`: `$color:start_window_background`（`#FFFFFF`）

### 显示 / 关闭

- 显示：`EntryAbility.onWindowStageCreate` 先 `SplashScreen.show(...)`，再启动 RN（`pages/Index`）
- 关闭：`src/navigation/rootStack.harmony.tsx`  
  `onReady` → `requestAnimationFrame` + `setTimeout(50)` → `SplashScreen.hide()`  
  （多等 50ms，避免关掉后短暂白屏）

## iOS

当前**没有**品牌 PNG，用的是 RN 默认 LaunchScreen 文案（「SAMRApp」+「Powered by React Native」）。

### 改成图片闪屏（推荐）

1. 把闪屏 PNG 拖进 Xcode 的 `Images.xcassets`（例如命名 `LaunchScreen`）
2. 打开 `ios/SAMRApp/LaunchScreen.storyboard`
3. 去掉两个 Label，加一个全屏 `UIImageView`
4. Image 选中刚加的 Asset，Content Mode 用 `Aspect Fit` 或 `Aspect Fill`
5. 约束贴满 Safe Area 或整屏
6. 保持 `Info.plist` 里 `UILaunchStoryboardName = LaunchScreen`

`AppDelegate` 里 `RNSplashScreen.show()` 会继续用这份 LaunchScreen 做覆盖层，JS `hide()` 后关掉。不用改 Swift。

### 只改文案

直接改 `LaunchScreen.storyboard` 里两个 Label 即可。

---

## 不要做的事

- 不要把闪屏图放到 `src/assets/` 指望三端自动用上
- 不要改文件名 / 资源名（除非同步改 xml / ets / json5 / storyboard）
- 不要在业务页里再调 `SplashScreen.hide()`；只应在 Root 导航 `onReady` 关一次
- Metro reload 看不到新图，必须重装原生包

---

## 验收

冷启动应看到新图，并在进入登录页或首页前消失，中间尽量无白闪。

| 检查项         | 预期                                  |
| -------------- | ------------------------------------- |
| Android 冷启动 | `launch_screen.png`                   |
| Harmony 冷启动 | 先 `startIcon`，随即 `splashImg` 全屏 |
| iOS 冷启动     | Storyboard / Asset 新内容             |
| 进入 App 后    | 闪屏消失，落到 Auth 或 Main           |
