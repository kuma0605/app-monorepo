# 吸顶提示组件使用与开发指南 (`StickyNotice`)

本文用于介绍通用吸顶提示组件 `StickyNotice` 的设计思路、API 接口和在页面中的具体使用方法。

---

## 组件功能特点

`StickyNotice` 是一个高度可定制的吸顶（悬浮在屏幕顶部）提示组件，具有以下主要特点：

1. **跨平台兼容**：适配了 React Native (iOS/Android) 与 HarmonyOS 鸿蒙环境。
2. **多模式支持**：预设了四种常见的展示模式 (`info` | `success` | `warning` | `error`)，每种模式均拥有精心配置和谐的背景色、边框色、前缀图标及文字颜色。
3. **两套调用模式**：
   - **声明式（Props 模式）**：通过传入 `visible`、`onClose` 等属性在页面中控制。
   - **命令式（API 模式）**：利用全局单例模式，通过 `StickyNotice.show()` 或 `StickyNotice.success()` 快捷方法直接在业务逻辑中触发显示，无需维护页面 state。
4. **插槽（Slot 模式）与正文内容适配**：支持直接通过 `content` 属性或 `children` 插槽传入文字或自定义 React 节点。

---

## 引入组件

```typescript
import {StickyNotice} from '@/components';
```

## 使用方案

### 方案 A：命令式 API 模式（推荐，极简使用）

只需在页面的根布局或顶级 Container 中挂载一个无属性的 `<StickyNotice />`。之后就可以在页面中的任何地方通过静态方法展示提示。

#### 1. 页面布局中挂载空组件：

```tsx
import React from 'react';
import {View} from 'react-native';
import {StickyNotice} from '@/components';

export default function MyScreen() {
  return (
    <View style={{flex: 1}}>
      {/* 挂载一次即可接收静态 API 的显示指令 */}
      <StickyNotice />

      {/* 页面其他内容 */}
    </View>
  );
}
```

#### 2. 在业务逻辑中触发：

```typescript
// 1. 最简文本提示（标题默认为 "提示"）
StickyNotice.info('这是一条普通提示正文内容。');

// 2. 带自定义标题的提示
StickyNotice.success({
  title: '提交成功',
  content: '您的表单已经提交成功！',
});

// 3. 各种预设类型的快捷 API
StickyNotice.info({title: '通知', content: '提示详情...'});
StickyNotice.success({title: '成功', content: '操作完成！'});
StickyNotice.warning({title: '警告', content: '当前操作不可逆！'});
StickyNotice.error({title: '错误', content: '网络请求失败，请稍后重试。'});

// 4. 支持手动调用隐藏方法
StickyNotice.hide();
```

### 方案 B：声明式模式（通过 Props 控制）

在页面中维护本地状态，将属性显式绑定给组件：

```tsx
import React, {useState} from 'react';
import {View, Button} from 'react-native';
import {StickyNotice} from '@/components';

export default function MyScreen() {
  const [noticeVisible, setNoticeVisible] = useState(false);

  return (
    <View style={{flex: 1}}>
      <StickyNotice
        visible={noticeVisible}
        onClose={() => setNoticeVisible(false)}
        type="warning"
        title="重要警告"
        content="这是一款声明式绑定的提示，只有当状态 visible 为 true 时展示。"
      />

      <Button title="显示提示" onPress={() => setNoticeVisible(true)} />
    </View>
  );
}
```

## API 属性说明 (Props)

| 属性名     | 类型                                          | 默认值   | 必填 | 说明                                                 |
| :--------- | :-------------------------------------------- | :------- | :--- | :--------------------------------------------------- |
| `visible`  | `boolean`                                     | `false`  | 否   | 是否显示（声明式模式必填）                           |
| `onClose`  | `() => void`                                  | -        | 否   | 点击关闭按钮的回调                                   |
| `type`     | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | 否   | 提示类型展示样式                                     |
| `title`    | `string`                                      | `'提示'` | 否   | 首行提示标题文本                                     |
| `content`  | `React.ReactNode`                             | -        | 否   | 提示的正文内容（支持纯字符串或 React 节点）          |
| `children` | `React.ReactNode`                             | -        | 否   | 同 `content`（当不传 `content` 时将读取 `children`） |
| `style`    | `ViewStyle`                                   | -        | 否   | 允许传入自定义的外层 View 样式覆盖                   |
| `duration` | `number`                                      | -        | 否   | 自动关闭延时，单位毫秒（声明式默认不自动关闭）       |

## API 静态方法说明 (Static Methods)

当组件作为无状态单例（API 模式）使用时，可以使用以下静态方法：

#### `StickyNotice.show(options)`

通用显示方法。

```typescript
StickyNotice.show({
  type: 'success',
  title: '标题',
  content: '正文内容',
  duration: 4000, // 自定义自动关闭延时为 4 秒（若不传，在 API 模式下默认 3 秒关闭，传入 0 则不自动关闭）
});
```

#### `StickyNotice.hide()`

通用隐藏方法，可关闭当前显示的吸顶提示。

#### 快捷类型函数

- `StickyNotice.info(content | options)`
- `StickyNotice.success(content | options)`
- `StickyNotice.warning(content | options)`
- `StickyNotice.error(content | options)`

_注：若仅传入字符串，会作为内容正文展示，且标题默认为 “提示”。_

## 样式自定义与扩展

吸顶组件默认的视觉效果：

- 采用绝对定位 `position: 'absolute'` 以及较高层级 `zIndex: 9999`，位于页面容器顶部 10 像素。
- 包含了阴影效果（`shadowColor`/`elevation`），并在右侧加入了点击关闭的 `close` 图标。
- 若需要调整它的位置（例如页面顶部有自定义导航条导致被遮挡），可以在引入组件时传入 `style` 属性覆盖 `top` 属性：
  ```tsx
  <StickyNotice style={{top: 60}} />
  ```
