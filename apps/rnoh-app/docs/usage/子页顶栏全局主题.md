# 子页顶栏全局主题

Root 级全屏业务页与各 Tab 内 **子 Stack** 的系统顶栏（非 TabBar）通过同一套 `screenOptions` 统一风格，避免逐屏手写。

---

## 配置代码位置

| 项                        | 路径                                                                                                                                         |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 共享 `screenOptions` 工厂 | [`src/navigation/defaultSubStackScreenOptions.tsx`](../../src/navigation/defaultSubStackScreenOptions.tsx)                                   |
| 挂载处                    | `rootStack` 的 `*.tsx`（Native Stack）与 `.harmony.tsx`（JS Stack，鸿蒙）中的 `screenOptions` 工厂调用；后续如新增 Tab Stack，再复用同一工厂 |

React Navigation 本身没有「全局注册表」；工程上的全局 = **一处实现 + 各子 Stack 引用同一函数**。

---

## 当前约定

- **背景色**：`#171933`（`headerStyle.backgroundColor`，并去掉阴影：`shadowOpacity: 0`、`elevation: 0`）。
- **标题**：白色（`headerTintColor`、`headerTitleStyle`），**居中**（`headerTitleAlign: 'center'`）。
- **返回**：仅当 `navigation.canGoBack()` 为真时展示；使用 `@ant-design/react-native` 的 `Icon`，`name="right"` 配合 `transform: rotate(180deg)` 作为向左箭头；`headerBackVisible: false` 避免与原生返回叠层；点击调用 `navigation.goBack()`。

首屏或单独设置了 `headerShown: false` 的 Screen 不受影响；单屏仍可在其 `options` 里覆盖任意字段。

## 代码示例

### 1. 在子 Stack 上挂载（与项目一致）

当前项目没有 Tab 内 Stack。后续如确实新增 Tab Stack，Native Stack 与鸿蒙 JS Stack 写法相同：引入工厂并传给 `screenOptions`。

```tsx
import {createNativeStackNavigator} from '@react-navigation/native-stack';
// 鸿蒙：import {createStackNavigator} from '@react-navigation/stack';

import {defaultSubStackScreenOptions} from './defaultSubStackScreenOptions';

type ExampleStackParamList = {
  ExampleHome: undefined;
  ExampleDetail: {id: string};
};

const Stack = createNativeStackNavigator<ExampleStackParamList>();

export function ExampleStackNavigator() {
  return (
    <Stack.Navigator screenOptions={defaultSubStackScreenOptions}>
      <Stack.Screen
        name="ExampleHome"
        component={ExampleHomeScreen}
        options={{headerShown: false}}
      />
      <Stack.Screen
        name="ExampleDetail"
        component={ExampleDetailScreen}
        options={{title: '详情'}}
      />
    </Stack.Navigator>
  );
}
```

### 2. 单屏覆盖默认顶栏

继承全局背景与标题色，只改某一屏的标题或隐藏顶栏：

```tsx
<Stack.Screen
  name="SomeScreen"
  component={SomeScreen}
  options={{
    title: '自定义标题',
    // 或完全隐藏系统栏（例如全屏页）
    // headerShown: false,
  }}
/>
```

动态标题（依赖路由参数）仍用 `options={({ route }) => ({ title: '...' })}`，会与 `screenOptions` 合并，后者先应用、单屏 `options` 覆盖同名键。

### 3. 共享工厂在做什么（结构示意）

完整实现见 `defaultSubStackScreenOptions.tsx`。逻辑上等价于：无历史栈时不画返回键；可返回时关掉原生返回、用自定义 `headerLeft`。

```tsx
// 示意：非拷贝粘贴源码，仅说明合并到 screenOptions 的字段
function defaultSubStackScreenOptions({navigation}) {
  const canGoBack = navigation.canGoBack();
  return {
    headerStyle: {
      backgroundColor: '#171933',
      shadowOpacity: 0,
      elevation: 0,
    },
    headerTintColor: '#fff',
    headerTitleStyle: {color: '#fff'},
    headerTitleAlign: 'center',
    ...(canGoBack
      ? {
          headerBackVisible: false,
          headerLeft: () => (
            <Pressable onPress={() => navigation.goBack()}>
              <Icon
                name="right"
                color="white"
                style={{transform: [{rotate: '180deg'}]}}
              />
            </Pressable>
          ),
        }
      : {}),
  };
}
```

## 修改或扩展时

1. 改视觉/交互：优先只改 `defaultSubStackScreenOptions.tsx`，双端与鸿蒙会一起生效。
2. 新增 Tab 子 Stack：只有确实需要 Tab 内 push/pop 时才创建 Stack，并在对应 `Stack.Navigator` 上增加 `screenOptions={defaultSubStackScreenOptions}`，同时保留 `.harmony.tsx` 与默认平台文件一致。单页面 Tab 直接挂 Screen，不额外包 Stack。
3. 路由注册、跳转与类型：仍见 [导航指南.md](./导航指南.md)。
