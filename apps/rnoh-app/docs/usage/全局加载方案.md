# 全局 Loading 实现方案指南 (Axios + Redux + SpinKit)

本指南介绍如何在项目中实现一个全局自动 Loading 体系（Redux 状态驱动 + 顶层遮罩 UI + 请求层计数器）。

## 1. 核心思路

1.  **计数器机制**：维护一个全局变量 `requestCount`，请求开始时 +1，结束/失败时 -1。
2.  **状态触发**：当计数器从 0 变 1 时，触发全局 `isLoading = true`；当计数器变回 0 时，触发 `isLoading = false`。
3.  **UI 展示**：在 `App.tsx` 最顶层渲染 `LoadingOverlay` 组件，受 Redux 状态控制。
4.  **对称性约束（必须满足）**：只有“参与全局 Loading 的请求”才允许 +1/-1；跳过 Loading 的请求绝不能影响计数器，否则会导致并发场景下 Loading 被提前关闭或计数被减到负数。

## 3. 实现步骤

### 第一步：创建 Redux Slice

在 `src/store/slices/globalSlice.ts` 中管理加载状态：

```typescript
import {createSlice, PayloadAction} from '@reduxjs/toolkit';

const globalSlice = createSlice({
  name: 'global',
  initialState: {
    isLoading: false,
  },
  reducers: {
    setLoading: (state, action: PayloadAction<boolean>) => {
      state.isLoading = action.payload;
    },
  },
});

export const {setLoading} = globalSlice.actions;
export default globalSlice.reducer;
```

### 第二步：在请求层统一接入全局 Loading

本项目已内置 Axios 封装：`src/services/apiClient.ts`。

为避免某些错误路径（例如 axios error 被转换成自定义 `NetworkError`）导致拦截器漏掉 `hide`，本项目采用更稳的方式：**在 `request()` 的 `try/finally` 中统一做 show/hide**，保证成功/失败都能成对执行。

#### 2.1 在 `apiClient.ts` 中增加注入点与计数器，并在 `request()` 中兜底

核心点是：在 `request()` 内先判断本次是否参与全局 Loading（默认参与，显式跳过才不参与），然后用 `try/finally` 保证 +1/-1 严格对称。

```typescript
// apiClient.ts 内新增：
export interface RequestConfig {
  headers?: Record<string, string>;
  timeout?: number;
  signal?: AbortSignal;
  params?: Record<string, unknown>;
  noLoading?: boolean; // 可选：跳过全局 Loading
}

type GlobalLoadingHandler = (isLoading: boolean) => void;
let _globalLoadingHandler: GlobalLoadingHandler = () => {};
export function setGlobalLoadingHandler(handler: GlobalLoadingHandler) {
  _globalLoadingHandler = handler;
}

let requestCount = 0;
let showTimer: ReturnType<typeof setTimeout> | null = null;
let hideTimer: ReturnType<typeof setTimeout> | null = null;
let lastShownAt = 0;

const SHOW_DELAY_MS = 0;
const MIN_VISIBLE_MS = 200;

function shouldUseGlobalLoading(config: {
  headers?: unknown;
  noLoading?: boolean;
}) {
  const headerNoLoading = (config.headers as any)?.['x-no-loading'];
  return !(headerNoLoading || config.noLoading);
}

function showGlobalLoading() {
  if (requestCount === 0 && !showTimer) {
    // 如果上一轮“延迟关闭”还在排队，新请求开始时要取消，否则可能误关新一轮 loading
    if (hideTimer) {
      clearTimeout(hideTimer);
      hideTimer = null;
      // 此时 Loading 已经是显示状态，更新时间并直接增加计数，不需要重新设置 showTimer 延迟
      lastShownAt = Date.now();
      requestCount += 1;
      return;
    }

    if (SHOW_DELAY_MS <= 0) {
      lastShownAt = Date.now();
      _globalLoadingHandler(true);
    } else {
      showTimer = setTimeout(() => {
        showTimer = null;
        if (requestCount > 0) {
          lastShownAt = Date.now();
          _globalLoadingHandler(true);
        }
      }, SHOW_DELAY_MS);
    }
  }
  requestCount += 1;
}

function hideGlobalLoading() {
  requestCount -= 1;
  if (requestCount <= 0) {
    requestCount = 0;
    if (showTimer) {
      clearTimeout(showTimer);
      showTimer = null;
      return;
    }
    const elapsed = Date.now() - lastShownAt;
    const remaining = Math.max(0, MIN_VISIBLE_MS - elapsed);
    if (remaining > 0) {
      // 最短展示需要“延迟关闭”，但要可取消 + 二次检查，避免竞态误关新请求的 loading。
      if (hideTimer) {
        clearTimeout(hideTimer);
      }
      hideTimer = setTimeout(() => {
        hideTimer = null;
        if (requestCount === 0) {
          _globalLoadingHandler(false);
        }
      }, remaining);
    } else {
      if (hideTimer) {
        clearTimeout(hideTimer);
        hideTimer = null;
      }
      _globalLoadingHandler(false);
    }
  }
}

// request() 内（推荐：用 try/finally 兜底，避免错误转换导致漏 hide）
async function request<T>(
  method: string,
  path: string,
  body?: unknown,
  config: RequestConfig = {},
) {
  const usesGlobalLoading = shouldUseGlobalLoading({
    headers: config.headers,
    noLoading: config.noLoading,
  });
  if (usesGlobalLoading) showGlobalLoading();

  try {
    // ... 构造 axiosConfig 并请求
  } finally {
    if (usesGlobalLoading) hideGlobalLoading();
  }
}
```

#### 2.2 在 `store` 初始化时注入 handler（把 loading 写回 Redux）

在 `src/store/index.ts`：

```typescript
import {setGlobalLoadingHandler} from '../services/apiClient';
import globalReducer, {setLoading} from './slices/globalSlice';

// rootReducer 里加入 global: globalReducer

setGlobalLoadingHandler(isLoading => store.dispatch(setLoading(isLoading)));
```

### 第三步：创建 Loading 组件

创建 `src/components/LoadingOverlay.tsx`：

```tsx
import React from 'react';
import {Modal, StyleSheet, View} from 'react-native';
import Spinner from 'react-native-spinkit';
import {useAppSelector} from '../store/hooks';

export function LoadingOverlay() {
  const isLoading = useAppSelector(state => state.global.isLoading);

  return (
    <Modal
      visible={isLoading}
      transparent
      statusBarTranslucent
      animationType="fade"
      onRequestClose={() => {}}>
      <View style={styles.container} pointerEvents="auto">
        <View style={styles.mask}>
          <Spinner type="ChasingDots" size={50} color="#FFFFFF" />
        </View>
      </View>
    </Modal>
  );
}

const styles = StyleSheet.create({
  container: {
    ...StyleSheet.absoluteFillObject,
    backgroundColor: 'rgba(0,0,0,0.2)',
    justifyContent: 'center',
    alignItems: 'center',
  },
  mask: {
    padding: 20,
    backgroundColor: 'rgba(0,0,0,0.6)',
    borderRadius: 10,
  },
});
```

### 第四步：根布局注入

在 `App.tsx` 中引入组件：

```tsx
import {LoadingOverlay} from './src/components/LoadingOverlay';

const App = () => {
  return (
    <Provider store={store}>
      <NavigationContainer>
        <RootNavigator />
        <LoadingOverlay /> {/* 放置在导航器同级 */}
      </NavigationContainer>
    </Provider>
  );
};
```

## 4. 进阶建议

1.  **局部跳过**：对于静默刷新的接口，调用时传入自定义 header：
    ```javascript
    axios.get('/api/poll', {headers: {'x-no-loading': 'true'}});
    ```
2.  **防止闪烁（按需开启）**：
    - 最短展示：`MIN_VISIBLE_MS`（例如 350ms），避免“刚出现就消失”的抖动；
    - **竞态处理（推荐）**：如果你实现了“最短展示”的延迟关闭，请把关闭定时器做成可取消（例如 `hideTimer`），并在触发时二次检查 `requestCount===0`，避免新请求被旧定时器误关；
    - 可选延迟：如果短请求导致遮罩频繁闪烁，再把 `SHOW_DELAY_MS` 调到 150–250ms。
3.  **更强的可维护性（推荐）**：
    - 不要在 `apiClient.ts` 内直接 import `store`（可能造成循环依赖/初始化时序问题），用 `setGlobalLoadingHandler` 在 `store` 初始化时注入；
    - 为 `setLoading` 补齐 payload 类型，以及 `useSelector` 使用 `RootState`，避免 `any` 扩散。
4.  **多实例支持**：如果你有多个 axios 实例，把“计数器 + 拦截器”封装成一个可复用的 `attachGlobalLoadingInterceptors(instance, dispatch)`，对每个实例调用一次即可。
