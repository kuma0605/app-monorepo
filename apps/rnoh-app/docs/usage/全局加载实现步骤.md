# 全局 Loading 从 0 落地步骤（本项目版本）

本文按当前项目结构（Redux Toolkit + `src/services/apiClient.ts` + `react-native-spinkit`）给出从 0 实现“全局 Loading 遮罩”的**最短可落地路径**。

> 实现细节与代码片段可参考：`docs/usage/全局加载方案.md`

## 0. 先统一约定：哪些请求参与全局 Loading

- **默认参与**：所有通过 `apiClient` 发出的请求都会触发全局遮罩（更符合“提交/防连点”的预期）。
- **跳过方式（任选其一）**：
  - **推荐**：调用 `apiClient` 时传 `noLoading: true`
  - **兼容**：请求头带 `x-no-loading: 'true'`

## 1) 确认依赖

确保已安装（本项目 `package.json` 已包含）：

- `@react-native-ohos/react-native-spinkit`
- `react-native-spinkit`

## 2) 新建 Redux Slice：`globalSlice`

创建 `src/store/slices/globalSlice.ts`，包含：

- state：`isLoading: boolean`
- action：`setLoading(boolean)`

## 3) 把 `globalSlice` 接入 store

修改 `src/store/index.ts`：

- 在 `combineReducers` 增加 `global: globalReducer`
- 保持 `RootState` / `AppDispatch` 的导出（项目已具备）

## 4) 在 `apiClient` 内接入“计数器 + try/finally 兜底”

修改 `src/services/apiClient.ts`，完成三件事：

### 4.1 增加注入点：`setGlobalLoadingHandler`

新增 `setGlobalLoadingHandler((isLoading: boolean) => void)`，由外部（store 初始化处）注入。

- **目的**：避免在 `apiClient.ts` 内直接 `import store`，降低循环依赖/初始化时序风险。

### 4.2 计数器与最短展示

- `requestCount`：并发请求计数
- `MIN_VISIBLE_MS`：最短展示时间（定为 200ms），给 iOS 原生 Modal 转场以动画完成的缓冲时间，彻底避免关闭卡顿。
- **竞态处理（推荐）**：最短展示通常需要“延迟关闭”，请把关闭定时器做成可取消（例如 `hideTimer`），并在触发时二次检查 `requestCount===0`，避免新请求被旧定时器误关。同时当 `hideTimer` 活跃时新发请求应取消定时器并直接增加计数，防止新请求极速完成导致遮罩卡死。
- `SHOW_DELAY_MS = 0`：默认不延迟展示（更适合提交/防连点）

### 4.3 try/finally 兜底（关键）

为保证“不管请求成功/失败/抛出自定义错误（如 NetworkError）都一定会关闭 Loading”，推荐把 show/hide 放到 `request()` 的 `try/finally`：

- **进入 try 之前**：判断本次是否参与全局 Loading（默认参与；显式 `noLoading` / `x-no-loading` 才跳过），参与则 +1（show）
- **finally**：只要参与过，就一定 -1（hide），从根上避免“loading 卡住不消失”

同时让 `RequestConfig` 支持 `noLoading?: boolean`，并在构造 axios config 时把它透传进去。

## 5) 在 store 初始化完成后注入 handler

仍在 `src/store/index.ts`：

- 在 store 创建完后调用：
  - `setGlobalLoadingHandler((isLoading) => store.dispatch(setLoading(isLoading)))`

这样 `apiClient` 就能把“loading 开/关”写回 Redux：`state.global.isLoading`。

## 6) 新建全局遮罩组件：`LoadingOverlay`

创建 `src/components/LoadingOverlay.tsx`：

- 从 `useAppSelector((s) => s.global.isLoading)` 读取状态
- 控制挂载与显示：**保持组件在 React 树中挂载**，仅通过 `visible={isLoading}` 属性控制原生 Modal 显隐，不要直接 `return null` 卸载组件，以便 iOS 原生安全执行淡出动画。

## 7) 在根组件挂载遮罩

修改 `App.tsx`：

- 在 `<RootNavigator />` 同级渲染 `<LoadingOverlay />`

## 8) 业务侧怎么用（验收方式）

- **默认**：`apiClient.get/post/...` 自动触发全局遮罩
- **跳过全局遮罩**（轮询/静默刷新等）：

```ts
apiClient.get('/poll', {noLoading: true});
```

或：

```ts
apiClient.get('/poll', {headers: {'x-no-loading': 'true'}});
```
